Other facts the plan rests on:
- No section uses a top-level name another section declares (0 of 334), so sections are textually independent.
- 138 sections already build their own SIM (`new Function(src…`); 157 touch `PROG`; 177 lines assign `api.HOOK.msg`.
- One SIM build is about 0.5 s (0.38 s of it `makeWorld`). Reusing the generated world across builds made builds
  *slower* (3–6 s each, cause not found): don't.
- `--isolation` compares pass/fail counts only, so it cannot see any of the 19.

**The plan** (platform; steps 1–2 are S, step 3 is M):
1. **`--isolation` compares what each check prints**, numbers followed by `ms`, `µs` or `s` masked, and lists the
   checks that differ. Run it before a milestone review, not in smoke. Acceptance: it reports the 11 above.
2. **`fresh()` in the prelude** (the existing `new Function` as a function; `api` and the destructured names become
   `let`), and `shards.mjs`'s `build()` emits, before each section, `api = fresh(); ({kepler, …} = api); log.length = 0;`
   and the `HOOK.msg` line. `iso.mjs` does exactly this by text surgery and is the reference. Acceptance: `--isolation`
   (step 1) reports only timings and seeds; a section's result is the same in `--smoke`, the full run and alone.
3. **Lazily, by lane**: delete the save/restore blocks and `resetHome()` calls sections carry for the old sharing
   (37 use `resetHome`), and re-pin the 11 checks whose honest value changed (none flips today).
- **Cost**: about 0.5 s more for each of the ~196 sections that don't already build a SIM, so roughly 100 CPU-seconds
  on the full run (about 25 s of wall time at `--jobs 4`). My own timing of this was too noisy to quote; measure it
  with `--times` on a quiet machine before and after.
- **Not chosen**: snapshot and restore of the SIM's module state (a list to keep in step with the code, which is the
  defect being fixed); a process per section (334 × Node start and module load).

## 4. Plan for R3: a lint step in `--smoke`

Three checks, all dependency-free, as one new section `platform-7` (S):

**(a) Code swallowed by a `//` comment.** `swallow.mjs` is the prototype: find each line's comment (strings, templates
and regex literals skipped), and flag it when a tail of the comment starts like a statement, ends in `;` or `}` and
parses (`new Function`). On the tree before R4 it flags exactly R4's five lines. On today's tree it flags:
- `views.js:78` **real**: reference view 13 (entry char) never runs `S.throttle = 0; S.sasMode = 'retro'; markT = simT;`
  (since 2026-10-07). → R25
- `tests/core.mjs:1030, 1072, 1108, 1202` **real**: four sections' `api.HOOK.news = () => {};` restores, and at 1108
  the restore of `HOOK.msg` to the suite's log (since the 2026-10-08 "test isolation" commit; from §25 on, the failure
  log carries no flight messages). → R25
- Three false positives of one shape, prose then `word (…);` (`sim/program.js:193`, `app/gl.js:2136`,
  `app/program-ui.js:165`), plus `tests/economy.mjs:484` and `refset.mjs:7`. Requiring no space before a call's `(`
  removes all five and keeps every real hit. The check covers `sim/`, `app/`, `builder.js`, `views.js`, `tests/` and
  the `.mjs` tools. Fixtures: R4's five old lines and R25's five, kept as strings in the test.

**(b) `no-undef` across the shared scope.** Node ships acorn: `node --expose-internals` then
`require('internal/deps/acorn/acorn/dist/acorn')`. `app/scan.cjs` parses the 47 scripts as one scope and reports names
used and declared nowhere, duplicate top-level declarations, and load-time uses of a later `let`/`const`. Today: 2,565
top-level names, 3 undefined (all guarded by `typeof` or dead: `DEBUG_PROC`, `recMenu`, `LIFT`, R32), 0 duplicates,
0 forward uses. So the check can go in strict from day one with a three-name allow-list. Risk: an internal Node path;
if a Node update moves it the section should fail loudly with that message, not skip. Run it as a child process from
the section (the flag can't be set from inside the suite's module).

**(c) Uniforms a shader reads and nothing sets** (`app/B_reach.cjs`): 22 programs, one real hit (R33). Cheap to keep.

`node --check` per file stays as platform-1.
