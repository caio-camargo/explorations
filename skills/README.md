# Skills

Project-specific Claude skills live here (one subdirectory per skill, each containing a
`SKILL.md`).

**This project has none, and probably shouldn't.** See `PROJECT.md` § Ground Rules — a one-off
toy doesn't earn a skill. This folder stays empty unless something here becomes genuinely
repeatable.

Framework-level meta-skills (`skill-status`, `skill-health`, `research-workflow`) are maintained
centrally, outside this repo, in
[claude-project-framework](https://github.com/caio-camargo/claude-project-framework/tree/main/shared/skills).
